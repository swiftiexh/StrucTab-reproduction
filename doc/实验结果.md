本文档是跨阶段结果的长期对比表。机器可读结果仍以各阶段的 `metrics.json` 和逐样本
JSONL 为准；只有在固定 100 条 subset 全部完成后，才向总表写入正式结果。

## 固定评测协议

- subset：`reproduction/data/splits/baseline_test.jsonl`
- 样本数：100，sample ID 与图像路径均唯一
- subset SHA-256：`f42bf3150c19c6480e0512eb9fbcb47072b6f4a8bfde9069328a142e1eebf89e`
- TEDS/TEDS-S：官方 StrucTab TEDS judger，单 worker
- 推理：BF16、greedy decoding、seed 42、`max_new_tokens=8192`
- 所有阶段必须使用相同 subset；不得将 TableVerse 样本用于训练

## 后续填写规则

1. 每个阶段保存独立 predictions、逐样本 TEDS 和 metrics，不能覆盖 baseline。
2. 确认 100 个 sample ID 与固定 subset 完全一致后再填写主结果表。
3. 同时记录 checkpoint、attention backend、解码参数和评测代码版本。
4. 除总分外更新主分层表；重复退化必须以未闭合标签、长度上限和循环内容等证据确认。
5. 若发现新的典型失败模式，在本节追加样本，不删除历史案例。

## Phase 7～8：正式预训练 Go/No-Go 结论

最终结论为 **No-Go：因硬件条件阻塞，停止正式 Stage 1 与 Stage 2 训练**。该结论针对
本项目要求的论文对齐全参数训练，以及两阶段合计 7～8 小时内一次稳定完成的执行约束；
不表示数据管线或训练代码不可运行。

| 验收项 | 实测结果 | 判定 |
|---|---|---|
| 预算数据 | train base 320；Stage 1 960 条；Stage 2 320 条；完整序列最大 1,534 tokens | 通过 |
| Stage 1 soak | 24/24 steps；loss 有限；均值 0.922144；checkpoint 保存、重载成功 | 通过，但仅为诊断 |
| Stage 1 显存稳定性 | 清理后 allocated 5.6240 → 5.6240 GiB；出现一次可恢复 allocator warning | 短程通过 |
| Stage 2 soak | 完成 2/8 steps；第 3 步 backward 返回 `cudaErrorUnknown` | 失败 |
| WSL 系统证据 | `dxgkio_make_resident: Ioctl failed: -12` | GPU/共享内存驻留失败 |
| 总体 Go/No-Go | 报告 `decision=no-go` | 禁止启动正式训练 |

Stage 1 soak checkpoint 位于 `reproduction/checkpoints/soak/`，只用于验证训练、保存和重载
链路，不进入阶段指标总表，也不作为 Phase 8 的正式初始化模型。由于 Phase 7 没有正式
checkpoint，Phase 8 同时受到前置依赖阻塞；且其自身 soak 已暴露相同硬件风险。项目由此
收束为方法级 Demo，不产生 Stage 1/Stage 2 TEDS、TEDS-S 或性能提升声明。
